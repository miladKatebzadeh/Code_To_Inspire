# BrightTech Project

Welcome to the BrightTech project workspace.

This directory contains the main files and resources for the project. We use a clear directory structure so that team members can quickly find the information they need.

## Directory Structure

- Documentation/ — Project documentation, guides, and team notes
- Scripts/ — Scripts used for project tasks
- Images/ — Project images and diagrams
- Reports/ — Project status and progress reports

## Working with the Project

Before working on project files, make sure you know where you are in the filesystem and where the files you need are located.

Some useful Linux commands for exploring this project are:

pwd
ls
ls -a
cd
