# Team Notes

## File Organization Rules

Please keep the project workspace organized.

Documentation files should be stored in the Documentation directory.

Scripts should be stored in the Scripts directory.

Images and diagrams should be stored in the Images directory.

Project reports should be stored in the Reports directory.

## Important

Do not place temporary files in the main project directory unless they are required there.

A clean directory structure makes it easier for team members to find information and helps internal tools work with project documents more efficiently.
