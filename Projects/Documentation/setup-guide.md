# Project Setup Guide

## Basic Setup

Before starting work on the project, review the project documentation and make sure you understand the directory structure.

The main project directories are:

- Documentation
- Scripts
- Images
- Reports

## Recommended Steps

1. Open the project directory.
2. Review the README file.
3. Explore the Documentation directory.
4. Check the available scripts.
5. Review the latest project report.

## Linux Commands

You can use the following commands to explore the project:

pwd
ls
cd

These commands will help you understand your current location and move between directories.

More file management and search commands will be introduced in later lessons.
